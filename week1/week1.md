📘 데이터베이스 키와 ERD 정리
🔑 기본키 (Primary Key)
역할: 각 행(Row)을 고유하게 식별해줌

특징:

중복 불가

NULL 값 허용 안 됨

🔗 외래키 (Foreign Key)
역할: 두 테이블을 서로 연결하는 데 사용되는 키

다른 테이블의 기본키(Primary Key)를 참조함

테이블 간의 **관계(연관성)**을 표현할 수 있음

🧩 복합키 (Composite Key)
두 개 이상의 칼럼(Column)으로 구성된 기본키

하나의 키만으로는 고유성을 보장하기 어려울 때 사용

예시: 학생ID + 과목코드 = 복합 기본키

🔁 연관관계 (Association)
**두 도메인(객체 또는 테이블)**이 서로 논리적인 관계를 갖고 연결된 상태

▶️ 단방향 연관관계
참조용 필드를 한쪽만 갖고 있는 구조

참조 필드를 가진 쪽에서만 반대쪽을 참조할 수 있음

🔁 양방향 연관관계
참조용 필드를 양쪽 모두 갖고 있는 구조

양쪽에서 서로를 참조할 수 있음

🧭 ER 다이어그램 (ERD)
Entity - Relationship Diagram

데이터베이스 구조를 시각화한 다이어그램

Entity(엔터티): 테이블

Relationship(관계): 엔터티 간의 관계 (외래키 등으로 표현)

Diagram(다이어그램): 전체 구조를 도식화

💡 ERD의 중요성
복잡한 데이터 구조를 한눈에 파악 가능

데이터 간의 관계 정의 및 설계 용이

협업 및 문서화에 효과적
